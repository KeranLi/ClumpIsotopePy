# Clump History GUI 使用说明

## 功能概述

团簇同位素热历史正演模拟GUI工具，用于模拟碳酸盐团簇同位素(Δ47)在不同热历史条件下的固态重排过程。

## 启动方式

### 方法1: 直接运行GUI模块
```bash
cd clump_history
python run_gui.py
```

### 方法2: 使用Python模块方式
```bash
cd clump_history
python -m clump_history gui
```

### 方法3: 安装后使用
```bash
pip install -e .
clump-history-gui
```

## 界面说明

### 1. 数据文件
- **热历史 CSV**: 包含时间和温度数据的CSV文件
  - 时间列: 默认 "Time/Myr" (百万年)
  - 温度列: 默认 "Avg_T/Celsius" (摄氏度)
  
- **实测数据 CSV**: 包含实测Δ47值的CSV文件
  - Δ47列: 默认 "Delta47"
  - 误差列: 默认 "SD" (标准差)

### 2. CSV列名设置
根据你的CSV文件实际列名进行修改，例如：
- 时间列: `Time/Myr`, `Age_Ma`, `Time_Myr` 等
- 温度列: `Avg_T/Celsius`, `Temperature`, `Temp_C` 等
- Δ47列: `Delta47`, `D47`, `Δ47` 等
- 误差列: `SD`, `Error`, `1sd` 等

### 3. 模型参数
- **矿物类型**: `calcite` (方解石) 或 `dolomite` (白云石)
- **参考文献**: 默认为 `HH21` (Hemingway & Henkes, 2021)
- **初始标准差**: 初始Δ47的不确定性，默认 0.02

### 4. 潜在热历史设置 (U-Fit)
- **时间窗口**: 定义需要调整的温度峰值区间 (Myr)
  - 开始时间: 峰值窗口起始时间
  - 结束时间: 峰值窗口结束时间
  
- **峰值温度**: 要测试的最大温度值，空格分隔多个值
  - 例如: `150 200 250 300 350` 表示测试5个不同峰值温度
  - 工具会自动使用U型曲线拟合来调整热历史

- **不包含初始场景**: 勾选后只绘制峰值温度场景，不绘制原始热历史

### 5. 绘图设置
- **Y轴范围**: Δ47值的显示范围 (默认 0.15 - 0.68)
- **温度刻度步长**: 右侧温度轴的刻度间隔 (默认 50°C)
- **显示图表**: 勾选后会在运行后弹出交互式图表窗口

### 6. 输出设置
- **输出目录**: 图表保存的文件夹路径
- **文件前缀**: 输出文件的命名前缀

## 工作流程

1. **准备数据文件**
   - 热历史CSV: 包含时间和温度列
   - 实测数据CSV: 包含Δ47和误差值

2. **设置参数**
   - 选择文件
   - 确认列名匹配
   - 设置矿物类型
   - 定义潜在热历史的时间窗口和峰值温度

3. **运行分析**
   - 点击"运行分析"按钮
   - 等待计算完成
   - 查看输出目录中的结果图表

4. **查看结果**
   - 图表包含多个子图，每个峰值温度一个
   - 每个子图显示:
     - 正演模拟的Δ47演化曲线
     - 误差填充区域
     - 平衡值曲线
     - 实测数据点 (在time=0处)

## 输出文件

运行后会生成以下文件（在输出目录中）：
- `{prefix}.svg` - SVG格式矢量图
- `{prefix}.pdf` - PDF格式矢量图

## 注意事项

1. **温度单位**: 输入CSV中的温度应为摄氏度(°C)，程序会自动转换为开尔文(K)
2. **时间单位**: 时间应为百万年(Myr)
3. **峰值温度**: 建议设置多个峰值温度进行对比分析
4. **计算时间**: 场景越多计算时间越长，请耐心等待

## 理论背景

本工具基于以下理论：
- Stolper & Eiler (2015) - 团簇同位素固态交换反应动力学
- Hemingway & Henkes (2021) - 无序动力学模型
- U-Fit方法 - 在保持地质约束的同时引入温度峰值

## 故障排除

**问题**: 提示"热历史文件未找到"
- 检查文件路径是否正确
- 尝试使用绝对路径

**问题**: 提示"列不存在"
- 检查CSV列名设置是否与实际文件匹配
- 注意大小写和特殊字符

**问题**: 计算结果异常
- 检查温度单位是否为摄氏度
- 检查时间窗口是否在数据范围内
- 检查矿物类型是否正确
