1. 下载 `ClumpHistoryGUI-v0.2.0.zip`
2. 解压到任意文件夹
3. 双击 `启动程序.bat` 或 `ClumpHistoryGUI.exe`

1. 下载 `ClumpHistoryGUI-Folder-v0.2.0.zip`
2. 解压到任意文件夹
3. 运行 `clump-history-gui.exe`

## 🚀 快速开始

### 第一次使用

1. **启动程序**
   ```
   双击 启动程序.bat
   ```

2. **等待加载**
   - 首次启动可能需要1-2分钟解压资源
   - 请耐心等待

3. **加载示例数据**
   - 热历史 CSV: `datasets/Thermal_History_Hu.csv`
   - 实测数据 CSV: `datasets/acutal_test_Hu.csv`

4. **设置参数**
   - 时间窗口: 550 - 600 Myr
   - 峰值温度: `150 200 250 300 350`

5. **运行分析**
   - 点击 "▶ 运行分析"
   - 右侧显示结果图表

6. **查看结果**
   - 使用工具栏进行缩放、平移
   - 结果自动保存到 `output_figures/`

### 参数详解

#### 数据文件
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 热历史 CSV | 包含时间和温度的文件 | `Thermal_History_Hu.csv` |
| 实测数据 CSV | 包含Δ47测量值的文件 | `acutal_test_Hu.csv` |

#### CSV列名设置
| 参数 | 说明 | 默认值 |
|------|------|--------|
| 时间列 | 时间数据所在的列名 | `Time/Myr` |
| 温度列 | 温度数据所在的列名 | `Avg_T/Celsius` |
| Δ47列 | Δ47数据所在的列名 | `Delta47` |
| 误差列 | 标准差所在的列名 | `SD` |

#### 模型参数
| 参数 | 说明 | 可选值 |
|------|------|--------|
| 矿物类型 | 碳酸盐矿物类型 | `calcite` / `dolomite` |
| 参考文献 | 使用的动力学模型 | `HH21` (Hemingway & Henkes, 2021) |
| 初始标准差 | 初始Δ47的不确定性 | 0.02 (默认) |

#### 潜在热历史设置 (U-Fit)
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 时间窗口 | 添加温度峰值的时间范围 | 550 - 600 Myr |
| 峰值温度 | 要测试的最大温度，空格分隔 | `150 200 250 300 350` |
| 不包含初始场景 | 只显示峰值场景 | 勾选/不勾选 |

#### 绘图设置
| 参数 | 说明 | 默认值 |
|------|------|--------|
| Y轴范围 (Δ47) | Y轴的最小最大值 | 0.15 - 0.68 |
| 温度刻度 | 右侧温度轴的刻度间隔 | 50 °C |

## 📊 结果解读

### 图表元素
- **蓝色实线**: 正演模拟的Δ47演化曲线
- **浅蓝色阴影**: 模拟结果的不确定性范围 (±1σ)
- **橙色虚线**: 平衡值曲线 (无动力学障碍的理论值)
- **黑色圆点**: 实测Δ47数据 (显示在time=0处)
- **右侧Y轴**: 对应的温度刻度

### 子图布局
- 每个峰值温度一个子图
- 默认显示2行3列布局
- 图例显示在每个子图的右下角

### 结果文件
运行后会生成以下文件：
```
output_figures/
├── forward_model.pdf    # PDF格式矢量图
└── forward_model.svg    # SVG格式矢量图
```

## 🛠️ 故障排除

### 常见问题

#### 问题1: 程序无法启动
**症状**: 双击exe没有反应

**解决方案**:
1. 检查是否被杀毒软件拦截
2. 以管理员身份运行
3. 检查Windows是否为64位

#### 问题2: 右侧图表不显示
**症状**: 运行后右侧空白

**解决方案**:
1. 最大化窗口
2. 检查输入数据是否正确
3. 查看状态栏的错误信息

#### 问题3: 计算结果异常
**症状**: 曲线明显不合理

**解决方案**:
1. 检查温度单位是否为摄氏度
2. 检查时间窗口是否在数据范围内
3. 确认矿物类型选择正确

#### 问题4: 首次启动很慢
**症状**: 双击后1-2分钟才显示窗口

**原因**: 单文件exe需要解压资源
**解决方案**: 正常现象，请耐心等待

### 错误代码

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| "ValueError: setting an array element" | NumPy版本不兼容 | 使用提供的exe文件 |
| "FileNotFoundError" | 文件路径错误 | 检查文件路径是否正确 |
| "KeyError: 'Time/Myr'" | CSV列名不匹配 | 修改列名设置为实际列名 |
| "RuntimeError: isotopylog compatibility" | 环境配置问题 | 使用打包好的exe文件 |

## 📚 数据格式规范

### 热历史CSV格式
```csv
Time/Myr,Avg_T/Celsius
0,50
10,55
20,60
...
500,120
```

**要求**:
- 第一列: 时间，单位百万年(Myr)
- 第二列: 温度，单位摄氏度(°C)
- 时间从小到大排列

### 实测数据CSV格式
```csv
Delta47,SD
0.520,0.015
0.518,0.012
0.522,0.016
```

**要求**:
- 第一列: Δ47值，单位‰
- 第二列: 标准差(1σ)
- 每行一个样本

## 🔬 科学原理简介

### 团簇同位素热历史正演

本软件基于以下科学原理：

1. **团簇同位素(Δ47)**
   - 测量碳酸盐中¹³C-¹⁸O键的丰度
   - 与温度相关，用于古温度重建

2. **固态重排动力学**
   - 高温下Δ47会向平衡值演化
   - 重排速率遵循Arrhenius方程

3. **正演模拟**
   - 给定热历史，计算Δ47演化
   - 对比实测值，约束热历史

### 参考模型
- **HH21**: Hemingway & Henkes (2021) 无序动力学模型
- 适用于方解石和白云石
